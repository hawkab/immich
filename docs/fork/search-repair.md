# Household photo search and duplicate comparisons

Text queries take precedence over a previously selected similar-photo reference.
Named queries resolve existing curated person names, including names on visible
partner photographs. Photo access checks still apply to every result.

The source-bound scene index supports Russian inflections and explicit lexical
equivalents. The installer performs resumable visual audits using compact atomic
observations and full edited previews. Generated evidence remains separate from
original files, capture dates, manual face annotations and descriptions.

Visible toys, models and represented subjects are included by default; users can
still choose the real-subject-only search setting.

`GET /duplicates/candidates` compares accessible timeline photographs by content,
size, filename, or capture time and dimensions. Content comparisons include exact
original checksums and native visual duplicate groups. File-property matches are
candidates, not proof of duplicate content. All comparison modes are read-only and
paginated, including partner photographs. Existing owner-only duplicate management
remains available in the Automatic groups tab.

`POST /cluster-groups/:id/reconcile-people` requires native group administration
access. It reassigns unnamed machine-learning faces while preserving every named
seed and manual annotation. Household membership is explicitly selected through
the common installer's private plan; new partners are not automatically joined.
